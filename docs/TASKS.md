## ترتيب التنفيذ

### P0 — تشغيل شريحة منتج مكتملة وآمنة

- [ ] **P0.1 توثيق وتشغيل المصادقة في تطبيق الهاتف:** إضافة تدفق تسجيل/دخول ولي الأمر بالبريد عبر Firebase Auth، وتنفيذ `TokenProvider` حقيقي يعيد Firebase ID token مع حالات sign-in/sign-out وتجديد الجلسة. لا تضمّن إعدادات أو مفاتيح Firebase في Git. أضف اختبارات للـprovider وتدفق الواجهة؛ إن لم توجد إعدادات Firebase، اترك الدمج قابلًا للإعداد ودوّن ما يتطلبه المالك.
  - القبول: لا يصل أي طلب محمي دون token؛ token صالح يرسل `Authorization: Bearer`؛ خروج المستخدم يمسح الحالة المحلية؛ لا توجد بيانات اعتماد في المستودع.
- [ ] **P0.2 إكمال دورة جلسة التعلم في Flutter:** شاشة/حالة بدء، إيقاف/إنهاء، نوع الجلسة ومدتها و`clientEventId` ثابت لكل حدث، ثم إرسالها إلى `/api/v1/children/{id}/study-sessions` وعرض سجل الجلسات مع حالات الشبكة والأخطاء.
  - القبول: الإعادة تحتفظ بنفس event ID ولا تنشئ سجلًا ثانيًا؛ معرف طفل من أسرة أخرى لا يكشف بيانات؛ اختبارات widget/repository تغطي دورة الجلسة.
- [ ] **P0.3 جعل API schema والاختبارات جزءًا من العقد:** توثيق request/response والأخطاء في OpenAPI، واختبار حدود الحقول والتواريخ وHTTP 401/404/409 لكل endpoint، والتحقق من عدم تسريب بيانات حساسة في السجلات.
  - القبول: يمكن توليد/عرض OpenAPI في Development؛ تنجح اختبارات تفويض وvalidation/idempotency؛ كل المسارات المحمية موصوفة.
- [ ] **P0.4 ضبط الترحيلات والتهيئة:** توثيق خطوات نشر migration، منع تشغيل عمليات تغيير schema عشوائية عند startup إن لزم، وإضافة تحقق بدء يمنع Production بلا Firebase Project ID أو Azure SQL connection. لا تضع أسرارًا حقيقية في الإعدادات أو السجلات.
  - القبول: يعمل SQLite في Development/Testing وSQL Server فقط خارجها؛ migration script قابل للتوليد؛ الإعداد الإنتاجي الناقص يفشل بإشارة آمنة وواضحة.

### P1 — إتمام التعلم الأساسي (ينتظر بعضه خيارات واعتمادات)

- [ ] **P1.1 اعتماد مصدر القرآن والتلاوة:** انتظر اختيار المستخدم وموافقته على شروط المصدر. بعد الموافقة فقط، وثّق الإصدار والحقوق وطريقة التحديث والبصمات واختبارات المطابقة. اعتمد ترخيصًا منفصلًا لكل تلاوة.
  - القبول: مصدر معتمد موثق؛ لا تغيير غير مصرح للنص؛ اختبار سلامة يطابق تعداد السور والآيات وبصمات إصدار المصدر؛ الإسناد ظاهر.
- [ ] **P1.2 تنفيذ فهرس السور والآيات ومشغل التلاوة:** لا تُفعّل بيانات فعلية قبل P1.1. حافظ على عرض حرفي للمحتوى الموثوق؛ تحكم تشغيل/إيقاف/إعادة وعدد مرات التكرار؛ حالات انقطاع الاتصال.
  - القبول: مطابقة مرجع المصدر؛ أدوات وصول مناسبة؛ لا placeholder يوهم بوجود محتوى حقيقي.
- [ ] **P1.3 تخزين/مزامنة غير متصل حسب ترخيص المصدر:** استعمل مسار المزامنة الذي يسمح به الترخيص المعتمد فقط؛ سجّل نسخة المحتوى ومزامنته وتعارضاتها، ولا تحتفظ بالموارد أطول من المسموح.
  - القبول: اختبار انقطاع/عودة اتصال ومزامنة متكررة دون فقد/تكرار؛ لا تخزين مخالف لشروط المصدر.
- [ ] **P1.4 إكمال ملف الطفل والتهيئة الأولية:** اختيار الطفل النشط، اختيار فئة عمرية عامة اختياريًا، لغة ومستوى/اهتمامات بالحد الأدنى، وسياسة حذف/تصدير قابلة للتنفيذ. تجنب جمع حقول لا تستخدمها ميزة فعلية.
