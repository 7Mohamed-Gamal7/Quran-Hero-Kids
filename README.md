# Quran Hero Kids

منصة تعليمية عائلية تساعد الأطفال على حفظ القرآن الكريم ومراجعته واختبار إتقانهم، مع أدوات متابعة وتحفيز مناسبة للعمر وإشراف الوالدين.

> هذا المستودع في مرحلة التأسيس والتنفيذ الأولي: توجد وثائق المنتج والبنية، ومشروع ASP.NET Core أولي مع `/health` واختبار تكاملي. لم يبدأ بعد تطبيق الهاتف أو منطق المنتج.

## الهدف

تقديم تجربة آمنة ومشجعة للأطفال بالعربية والإنجليزية، تعمل دون اتصال في وظائف التعلم الأساسية، وتمنح ولي الأمر رؤية عملية للتقدم دون منافسة اجتماعية عامة أو ضغط مفرط على الطفل.

## النطاق الأولي (MVP)

- حساب ولي أمر وإدارة ملفات الأبناء.
- اختيار سورة وآيات، الاستماع، وإعداد جلسات التكرار.
- تسجيل جلسات الحفظ والمراجعة والاختبارات النصية الأولية.
- أهداف يومية، تقدم، نقاط تحفيزية بسيطة، ولوحة ولي الأمر.
- مزامنة خلفية قابلة لإعادة المحاولة؛ دون إدخال الميكروفون أو تحليل التلاوة آليًا في الإصدار الأول.

## التقنية المستهدفة

- تطبيق: Flutter، مع Riverpod وClean Architecture.
- API: ASP.NET Core Web API.
- بيانات: Azure SQL / SQL Server.
- المصادقة: Firebase Authentication مع تحقق الرمز في الخادم.
- التخزين والإشعارات: Azure Blob Storage وFirebase Cloud Messaging عند الحاجة.
- الذكاء الاصطناعي والتعرّف الصوتي مؤجلان إلى ما بعد التحقق من جودة بيانات التلاوة والخصوصية.

## قرارات تأسيسية

- تخزين نص القرآن من مصدر موثوق ذي ترخيص واضح، مع حفظ بيانات المصدر والإصدار والتحقق من النص؛ لا يُنشأ النص القرآني بواسطة نموذج توليدي.
- حساب ولي الأمر هو نقطة التسجيل الأساسية، وملفات الطفل تابعة له ولا تتطلب حسابًا مستقلًا في MVP.
- لا تُطلق منافسة بين الأصدقاء أو مشاركة عامة لبيانات الأطفال ضمن MVP.
- أي تحليل آلي للتلاوة يُعامل كتقييم مساعد قابل للخطأ، ولا يستبدل المعلم أو ولي الأمر.
